# Changelog

## 0.2.0 — 2026-11-01

- Complete source reference: The 606-file pinned reference tree preserves packages, apps, shaders, examples, integration sources, tests and documentation. It is licensed foundation material, not newly authored LuxLeaf code.
- Active engines: `/react` builds the pinned 2.4.24 source with a documented query-string ESM compatibility patch. `/vue` exposes the complete 0.1.0 package. Three.js is pinned to the tested 0.180.0 version.
- LuxLeaf studio: Strict versioned settings, bounded share URLs, undo/redo, interpolation, mesh/shader controls, PNG export, all twelve shader pairs at `/shaders`, a Framer host adapter, and an offline Figma PNG import integration.
- Add source-inclusive package archives, foundation hash checks, and GitHub Packages publishing/consumer installation workflows.
